# التمارين

استخدم دفترًا، أو انسخ هذا الملف إلى مستودعك الخاص واكتب إجاباتك فيه.

## التمرين 1: اختراع أم ابتكار؟ (10 دقائق)

صنّف كل حالة: **اختراع** أم **ابتكار** أم **كلاهما**، واذكر أي ركائز الابتكار الأربع حسمت إجابتك.

1. باحث يصمّم مفهومًا لمستشعر قابل للارتداء لم يُصنَّع قط.
2. مستشفى يطبّق لأول مرة نظامًا إلكترونيًا موجودًا للمتابعة ويدرّب جميع الموظفين.
3. فريق يطوّر خوارزمية تشخيص جديدة ويطلقها في عيادات الرعاية الأولية.

## التمرين 2: اختبار الخصائص الخمس (10 دقائق)

حدّد لكل سيناريو الخصائص المتحققة (الحداثة، القصدية، التغيير غير الروتيني، تحقيق الفائدة، اتساع الأثر)، ثم احكم: **ابتكار أم لا؟**

| السيناريو | الحكم | السبب |
|---|---|---|
| ممرضة تغيّر عادتها الشخصية في تدوين الملاحظات ولا يتأثر أحد غيرها. | | |
| جناح يستخدم أداة جدولة ذكية لتقليل الانتظار ويعتمدها القسم كله. | | |
| عيادة تقل مواعيدها هذا الشهر لأن طبيبين غادرا. | | |

## التمرين 3: رسم الرحلة (10 دقائق)

خذ الابتكارات الأحد عشر في [الوحدة 3](../docs/03-impactful-innovations.md) وضعها ضمن: **العلاج** أو **التشخيص المبكر والرعاية عن بُعد** أو **الوقاية**. ثم اختر واحدًا واكتب جملتين عن الاحتياج الحقيقي الذي يلبّيه.

## التمرين 4: اكتشاف الاحتياجات في بيئتك (15 دقيقة)

راقب بيئة سريرية أو إدارية (أو تذكّر بيئة تعرفها جيدًا). دوّن **خمس نقاط ألم على الأقل** بهذا الشكل:

| # | من المتأثر؟ | ماذا يحدث؟ | كم مرة؟ | الخطر أو التكلفة |
|---|---|---|---|---|
| 1 | | | | |

## التمرين 5: تقييم الاحتياجات (10 دقائق)

قيّم نقاط الألم في التمرين 4 من 1 (منخفض) إلى 5 (مرتفع).

| الاحتياج | الأهمية | التكرار | أثره على سلامة المرضى | إمكانية المعالجة | المجموع |
|---|---|---|---|---|---|
| | | | | | |

اختر أهم احتياج واكتب **عبارة احتياج من جملة واحدة**:

> *وسيلة لمعالجة [المشكلة] لدى [الفئة]، بحيث [النتيجة المرجوة].*

## التمرين 6: توليد الحلول وتقييمها (15 دقيقة)

1. اكتب **خمس أفكار حلول على الأقل** لأهم احتياج (الهدف التنوع لا الجودة).
2. قيّمها وفق: الجدوى التقنية، والتنظيم والخصوصية، والجدوى الاقتصادية، وقبول المستخدمين.
3. اختر مفهومًا واحدًا وارسمه في بضعة أسطر أو مخطط بسيط.

## التمرين 7: مخطط التنفيذ (15 دقيقة)

أكمل خطة بنصف صفحة:

- **الاستراتيجية:** المتطلبات التقنية والموافقات والأشخاص والتدريب.
- **الجدول الزمني:** ضع جدولًا مرحليًا خاصًا بك (مثلًا 12 أسبوعًا: متطلبات، بيانات، بناء، تقييم، تحسين).
- **الدليل:** كيف ستُثبت أن الحل يعمل؟ (تذكّر تحفظ Sahl AI: الدراسة أحادية الذراع لا تثبت توفير الوقت.)
- **الاستدامة:** من يموّل الحل ويصونه بعد التجربة؟

## التمرين 8: تحليل دراسة الحالة (20 دقيقة)

املأ الخطوات الست لنموذج Biodesign لحالة **Sahl AI** في جدول بكلماتك الخاصة، ثم أجب: *ما نقطة الضعف في الدليل، وكيف تقوّيه؟* (تلميح: أعد قراءة التحفظ المتعلق بالدراسة أحادية الذراع.)

## مشروع ختامي (اختياري)

حوّل التمارين من 4 إلى 7 إلى مقترح مشروع قصير (صفحة إلى صفحتين) وأضفه إلى مستودعك على GitHub باسم `my-project/README.md`.
