# قاموس المصطلحات

| المصطلح (بالعربية) | المصطلح (Eng.) | المعنى |
|---|---|---|
| الابتكار | Innovation | تحويل أفكار جديدة أو محسّنة إلى حلول عملية تخلق قيمة. |
| الاختراع | Invention | إيجاد فكرة أو تقنية أو منتج جديد لم يكن موجودًا؛ ويركّز على الحداثة. |
| الحداثة / الجِدّة | Novelty | أن يكون الشيء جديدًا، ولو على البيئة التي يُطبَّق فيها فقط. |
| التطبيق الفعلي | Implementation | وضع الحل موضع الاستخدام الحقيقي. |
| ستانفورد بايوديزاين | Stanford Biodesign | نموذج منهجي (تحديد الاحتياج ← ابتكار الحل ← التنفيذ) للابتكار الطبي القائم على الاحتياجات. |
| اكتشاف الاحتياجات | Needs Finding | ملاحظة البيئة السريرية لاكتشاف الاحتياجات غير الملبّاة. |
| تقييم الاحتياجات | Needs Screening | تحليل الاحتياجات وترتيب أولوياتها. |
| توليد الحلول | Concept Generation | إنتاج أفكار حلول متنوعة. |
| تقييم الحلول | Concept Screening | تقييم الأفكار وفق معايير تقنية وتنظيمية واقتصادية. |
| تطوير استراتيجية التنفيذ | Strategy Development | تخطيط المتطلبات التقنية والسريرية والتنظيمية. |
| تخطيط المشروع | Business Planning | خطة تشغيلية ومالية وتمويل واستدامة. |
| كريسبر | CRISPR-Cas9 | تقنية تحرير الجينات التي يقوم عليها علاج Casgevy. |
| كاسجيفي | Casgevy | علاج قائم على كريسبر لمرض الخلايا المنجلية. |
| سيماغلوتايد | Semaglutide | دواء للسمنة دُرس في تجربة SELECT. |
| لقاح mRNA | mRNA Vaccine | لقاح يستخدم الحمض النووي الريبوزي المرسال. |
| الأجهزة القابلة للارتداء | Wearable Devices | أجهزة تُرتدى، كالساعات الذكية، تجمع بيانات صحية. |
| التعرف الآلي على الكلام | ASR | تحويل الكلام المنطوق إلى نص. |
| نموذج لغوي كبير | LLM | نموذج يولّد نصًا انطلاقًا من مدخلات. |
| مقياس PDQI-9 | PDQI-9 | مقياس من تسعة بنود لتقييم جودة الملاحظات السريرية. |
| كاتب الذكاء الاصطناعي المحيطي | Ambient AI Scribe | ذكاء اصطناعي يستمع إلى الزيارة ويصوغ الملاحظة. |
